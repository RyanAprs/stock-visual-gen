# stock-visual-gen (stockgen)

Generate **100% original** motion-graphics clips (yours to sell) + Adobe Stock CSV metadata.

Unlike `ytgen` (which downloads stock footage for YouTube videos), **everything here is rendered from code** — p5.js sketches → 4K MP4. You own the copyright outright, so these clips are legal to upload to Adobe Stock, Shutterstock, Pond5, etc.

## Why this exists
- ytgen clips = Pexels/Pixabay footage = **NOT resellable** (someone else's copyright).
- stockgen clips = generated by algorithms you run = **yours**. Sell freely.

## Pipeline
```
pick sketch + params  ->  render frames (p5.js headless, 4K)  ->  ffmpeg -> clip.mp4
                      ->  Ollama generates Adobe Stock CSV metadata (title/keywords/category)
```

## Output per clip
```
output/<batch>/
  clip_001.mp4            # 3840x2160 H.264, seamless loop
  clip_002.mp4
  ...
  metadata.csv           # Adobe Stock upload format (Filename,Title,Keywords,Category,Releases)
```

## Sketch library (all original, seeded/reproducible)
- `particles`  — flow-field particle systems (abstract motion)
- `gradient`   — flowing gradient / plasma fields
- `waves`      — layered sine-wave landscapes
- `nebula`     — cinematic bokeh / light / smoke loops
- `data`       — animated abstract data-viz shapes

## Setup
```bash
cd /Users/mac/Code/stock-visual-gen
uv venv --python 3.11 && uv pip install -e .
npm install                      # puppeteer for headless render
stockgen doctor
stockgen render --sketch particles --count 5 --seed-start 100
stockgen metadata                # generate metadata.csv for the batch
```
